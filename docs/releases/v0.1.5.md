An update to [brAInStudio 0.1.4](https://github.com/itubrainlab/brainstudio/releases/tag/v0.1.4),
whose Windows app failed its self-test. This release includes the Windows app.

## Fixes

- **Windows**: exporting a script failed because text files were read with Windows'
  default encoding. Every text file is now read and written as UTF-8.
- **XDF**: the EEG time grid was one sample short, so the whole recording was resampled
  for nothing and the last sample dropped. All samples are now kept as recorded.

## Changes

- **Short, readable exported scripts.** About 200–280 lines of plain MNE, MNE-BIDS,
  pyxdf, pymovements, AutoReject, scipy and pandas code, without brAInStudio, in four
  cells (Loading, Preprocessing, Epoching, Analysis), each opening with a short
  explanation. Checked against the app on synthetic data and on a 47-min, 64-channel
  XDF with Gazepoint gaze: the same preprocessed data and ICA bit for bit, the same
  epochs, ERP values, band power and indices.
- **AutoReject is fitted on all epochs by default** (for the ICA segments and for the
  epochs), with a *fit on %* setting. On a 47-min recording, fitting on a random share
  made the kept epochs depend on the draw (30–90 %); fitted on all epochs, 78 % ± 0.4 %.
  It costs memory (about 12× the epochs it is fitted on), which the memory check now
  includes.
- **No epoch cap**: every selected event becomes an epoch unless it is rejected (the
  random subsample of at most 2,000 per group is gone).
- **Gaze detection presets**: *pymovements defaults (raw gaze)* and *Gazepoint,
  fixation-filtered gaze (FPOG)* (dispersion 100 px, 60 ms minimum fixation,
  central-difference saccade velocity), chosen automatically from the data. On a GP3 HD
  recording the latter matches the tracker's own fixations (same count, 94 % of onsets
  within ±50 ms). New saccade velocity setting.

## Downloads

| System | File | Start |
|---|---|---|
| macOS (Apple Silicon) | `brAInStudio-0.1.5-macos-arm64.dmg` | open the DMG and drag brAInStudio to Applications; the first time, right-click → **Open** (the app is not notarized) |
| Windows (x86_64) | `brAInStudio-0.1.5-windows-x86_64.zip` | unzip and run `brAInStudio\brAInStudio.exe` (SmartScreen may ask you to confirm) |
| Linux (x86_64, glibc 2.35+) | `brAInStudio-0.1.5-linux-x86_64.tar.gz` | unpack and run `brAInStudio/brAInStudio` |
| Python | `brainstudio-0.1.5-py3-none-any.whl`, sdist | `pip install brainstudio-0.1.5-py3-none-any.whl` (Python ≥ 3.12) |

Each app was checked on its own system with `brAInStudio --self-test`. The self-test
loads a synthetic EEG and gaze dataset, then runs gaze event detection, preprocessing,
ICA with ICLabel, epoching with AutoReject, script export, ERP component statistics and
band power.

Full documentation: [README](https://github.com/itubrainlab/brainstudio#readme).
