A small update to [BrainStudio 0.1.0](https://github.com/itubrainlab/brainstudio/releases/tag/v0.1.0).

## Changes

- **New logo**: the brAIn lab brain, as in brAInStream, with a column of band-power
  bars (an EEG spectrum on its side: delta, theta, an alpha peak, beta, gamma) in place
  of brAInStream's binary digits. It is used for the app and window icons, the top bar
  and the packages.
- **Fix**: ERP, band-power and index plots no longer print a NumPy "Degrees of freedom
  <= 0" warning when a group has fewer than two values at some time point. The ± SEM
  band is simply not drawn there, as before.

## Downloads

| System | File | Start |
|---|---|---|
| macOS (Apple Silicon) | `BrainStudio-0.1.1-macos-arm64.dmg` | open the DMG and drag BrainStudio to Applications; the first time, right-click → **Open** (the app is not notarized) |
| Windows (x86_64) | `BrainStudio-0.1.1-windows-x86_64.zip` | unzip and run `BrainStudio\BrainStudio.exe` (SmartScreen may ask you to confirm) |
| Linux (x86_64, glibc 2.35+) | `BrainStudio-0.1.1-linux-x86_64.tar.gz` | unpack and run `BrainStudio/BrainStudio` |
| Python | `brainstudio-0.1.1-py3-none-any.whl`, sdist | `pip install brainstudio-0.1.1-py3-none-any.whl` (Python ≥ 3.12) |

Each app was checked on its own system with `BrainStudio --self-test`. The self-test
loads a synthetic EEG and gaze dataset, then runs preprocessing, ICA, epoching, ERP
component statistics and band power.

Full documentation: [README](https://github.com/itubrainlab/brainstudio#readme).
