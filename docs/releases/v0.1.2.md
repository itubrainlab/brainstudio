An update to [brAInStudio 0.1.1](https://github.com/itubrainlab/brainstudio/releases/tag/v0.1.1)
with fixes for real recordings and several changes to preprocessing and analysis.

## Fixes

- **Gaze/EEG alignment in XDF**:
  - Gaze now follows the timestamps when a tracker's sampling rate is not constant.
    Some Gazepoint recordings change rate partway through. The straight-line clock fit
    then misplaced gaze by up to ±2 s, by a different amount in each part of the
    recording, which no fixed gaze offset could correct.
  - Eye-tracker blinks now line up with the EEG for the whole session, and the info
    panel says when this correction was needed.
- **Large files no longer freeze the app**:
  - XDF, EDF and BIDS loading runs in the background.
  - Gaze samples sent as text are converted about 4× faster.
  - The event table is built once per load.
  - On a 217 MB XDF the preprocessed view now appears in about 8 s instead of 23 s.
- **Gaze offset and ICA**: changing the gaze offset or the gaze detection settings now
  rescores a fitted ICA against the new blinks and refreshes the component view and the
  blink check. Ticked components stay as they are.
- **ICA**:
  - The fit uses the channels kept in Preprocessing, not the file's bad list. This
    fixes "n_components cannot be greater than len(picks)".
  - The fit is bounded (a sample cap spread over the recording and an iteration cap),
    and the elapsed time is shown while it runs.
- **BIDS**:
  - Runs with different bad channels can be combined.
  - The IIR high-pass no longer fails when an annotation touches the start or end of
    the data.

## Changes

- **BIDS loading** reads:
  - the dataset's bad channels (`channels.tsv`);
  - electrode positions;
  - dataset information;
  - every `events.tsv` column, all usable as event filters in epoching groups.
- **Defaults**: preprocessing defaults to a 0.1–30 Hz band-pass with a 50 Hz notch.
- **Referencing** has moved into the analyses:
  - choosing an ERP component selects its reference: average for P1 and N170, mastoids
    for the others;
  - without a good mastoid pair, the data stay as recorded.
- **Band power** is normalised against the baseline per subject, not across subjects.
- **Epoching summary**: one column for each reason an event did not become an epoch
  (outside the recording, same sample, over the cap, amplitude, BAD annotation).
- **Title**: the window title shows the BIDS dataset folder, or "first + N more" when
  files are combined.
- **Removed**: the event-delay option.

## Downloads

| System | File | Start |
|---|---|---|
| macOS (Apple Silicon) | `BrainStudio-0.1.2-macos-arm64.dmg` | open the DMG and drag BrainStudio to Applications; the first time, right-click → **Open** (the app is not notarized) |
| Windows (x86_64) | `BrainStudio-0.1.2-windows-x86_64.zip` | unzip and run `BrainStudio\BrainStudio.exe` (SmartScreen may ask you to confirm) |
| Linux (x86_64, glibc 2.35+) | `BrainStudio-0.1.2-linux-x86_64.tar.gz` | unpack and run `BrainStudio/BrainStudio` |
| Python | `brainstudio-0.1.2-py3-none-any.whl`, sdist | `pip install brainstudio-0.1.2-py3-none-any.whl` (Python ≥ 3.12) |

Each app was checked on its own system with `BrainStudio --self-test`. The self-test
loads a synthetic EEG and gaze dataset, then runs preprocessing, ICA, epoching, ERP
component statistics and band power.

Full documentation: [README](https://github.com/itubrainlab/brainstudio#readme).
