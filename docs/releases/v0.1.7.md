An update to [brAInStudio 0.1.6](https://github.com/itubrainlab/brainstudio/releases/tag/v0.1.6).

## New

- **Stimuli in the screen view.** A BIDS dataset's images and videos (its `stimuli`
  folder) are shown in step with the timeline: each from its event's onset, for the
  event's duration in `events.tsv` (else until the next stimulus). Videos play frame by
  frame as you move the cursor or play the recording. The overview bar marks when
  stimuli were shown; the screen view names the file and also appears for EEG-only
  recordings with stimuli.
- **Map events to stimuli** (*Stimulus*, Ctrl+I): the event column that names the
  stimulus is BIDS `stim_file` when the events have it, else the column whose values
  name the most files (`image_id` 82 → `stimuli/82.png`). Each value can be mapped to
  another file, with a preview, and another folder chosen.
- Images are shown at their own size in the centre of the screen (scaled down to fit
  when larger). *Load one image for the whole recording* keeps the single-image option.

## Fixes

- **BIDS events**: in runs with eye-tracking messages, the messages replaced
  `events.tsv`, losing its columns. `events.tsv` is now the reference; messages add only
  other events.

## Downloads

| System | File | Start |
|---|---|---|
| macOS (Apple Silicon) | `brAInStudio-0.1.7-macos-arm64.dmg` | open the DMG and drag brAInStudio to Applications; the first time, right-click → **Open** (the app is not notarized) |
| Windows (x86_64) | `brAInStudio-0.1.7-windows-x86_64.zip` | unzip and run `brAInStudio\brAInStudio.exe` (SmartScreen may ask you to confirm) |
| Linux (x86_64, glibc 2.35+) | `brAInStudio-0.1.7-linux-x86_64.tar.gz` | unpack and run `brAInStudio/brAInStudio` |
| Python | `brainstudio-0.1.7-py3-none-any.whl`, sdist | `pip install brainstudio-0.1.7-py3-none-any.whl` (Python ≥ 3.12) |

Each app was checked on its own system with `brAInStudio --self-test`. The self-test
loads a synthetic EEG and gaze dataset with stimuli, then runs gaze event detection,
stimulus video decoding, preprocessing, ICA with ICLabel, epoching with AutoReject,
script export, ERP component statistics and band power.

Full documentation: [README](https://github.com/itubrainlab/brainstudio#readme).
