An update to [brAInStudio 0.1.3](https://github.com/itubrainlab/brainstudio/releases/tag/v0.1.3).

## Changes

- **Gaze processing with [pymovements](https://pymovements.readthedocs.io)**, in the app
  and in exported scripts; PyGaze is no longer used.
  - Fixations: I-DT. Saccades: the Engbert & Kliegl velocity threshold. Blinks: from
    the pupil signal, or from tracking loss without a pupil channel.
  - Fixation location, saccade amplitude and peak velocity come from pymovements, and
    fixations are mapped to the areas of interest with `Events.map_to_aois`.
  - Detection settings in the Controls panel: fixation dispersion, minimum fixation,
    saccade threshold (λ), minimum saccade, blink limits. Thresholds are in pixels.
  - Any sampling rate works, including irregular streams; event onsets are the exact
    sample times.
  - Detection runs in the background, so long recordings no longer freeze the window.
  - AOIs are rectangles (what pymovements maps); ellipse AOIs are gone.
- **Exported scripts run without brAInStudio.**
  - The brAInStudio code a script uses (reading XDF and BIDS with eye tracking, gaze
    events, the event table, epoching, the measure tables) is copied in unchanged, in a
    foldable block per section. Standard steps stay plain MNE, AutoReject and scipy
    code. The montage is built with standard MNE calls.
  - Each section (Loading, Preprocessing, Epoching, Analysis) opens with a
    plain-language explanation of what it does with the actual settings.
  - The first lines say what to install (MNE, MNE-BIDS, pymovements, AutoReject, …).
  - Checked with brAInStudio blocked: the scripts give the app's data, epochs and
    tables exactly.

## Downloads

| System | File | Start |
|---|---|---|
| macOS (Apple Silicon) | `brAInStudio-0.1.4-macos-arm64.dmg` | open the DMG and drag brAInStudio to Applications; the first time, right-click → **Open** (the app is not notarized) |
| Windows (x86_64) | `brAInStudio-0.1.4-windows-x86_64.zip` | unzip and run `brAInStudio\brAInStudio.exe` (SmartScreen may ask you to confirm) |
| Linux (x86_64, glibc 2.35+) | `brAInStudio-0.1.4-linux-x86_64.tar.gz` | unpack and run `brAInStudio/brAInStudio` |
| Python | `brainstudio-0.1.4-py3-none-any.whl`, sdist | `pip install brainstudio-0.1.4-py3-none-any.whl` (Python ≥ 3.12) |

Each app was checked on its own system with `brAInStudio --self-test`. The self-test
loads a synthetic EEG and gaze dataset, then runs gaze event detection, preprocessing,
ICA with ICLabel, epoching with AutoReject, script export, ERP component statistics and
band power.

Full documentation: [README](https://github.com/itubrainlab/brainstudio#readme).
