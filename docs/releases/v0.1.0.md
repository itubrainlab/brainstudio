First release of BrainStudio, a desktop app and Python library for simultaneous **EEG and
eye-tracking** recordings, built on MNE-Python and PyGaze.

## Downloads

| System | File | Start |
|---|---|---|
| macOS (Apple Silicon) | `BrainStudio-0.1.0-macos-arm64.dmg` | open the DMG and drag BrainStudio to Applications; the first time, right-click → **Open** (the app is not notarized) |
| Windows (x86_64) | `BrainStudio-0.1.0-windows-x86_64.zip` | unzip and run `BrainStudio\BrainStudio.exe` (SmartScreen may ask you to confirm) |
| Linux (x86_64, glibc 2.35+) | `BrainStudio-0.1.0-linux-x86_64.tar.gz` | unpack and run `BrainStudio/BrainStudio` |
| Python | `brainstudio-0.1.0-py3-none-any.whl`, sdist | `pip install brainstudio-0.1.0-py3-none-any.whl` (Python ≥ 3.12) |

Each app was checked on its own system with `BrainStudio --self-test`. The self-test
loads a synthetic EEG and gaze dataset, then runs preprocessing, ICA, epoching, ERP
component statistics and band power.

## What's in it

**Loading**
- XDF (LSL):
  - stream roles (EEG, gaze, markers, ignore), chosen automatically or by hand;
  - a stream dialog with per-channel settings;
  - clock-offset recovery and de-jittering.
- Multi-column marker streams: start/stop rows are paired into events with durations,
  and every column becomes a filterable event column.
- EDF/BDF, BrainVision, EEGLAB and FIF files, with a trigger channel → events step
  (integer codes with a bit mask, or analog pulses).
- BIDS datasets (EEG and eye tracking), and EyeLink `.asc`.
- Several files or BIDS runs combined into one recording. Events keep their subject,
  session, run and file.
- Gazepoint data: numeric samples sent as text, validity flags and pupil channels.

**Data tab**
- EEG traces (EEG channels only; preprocessed by default) with gaze and pupil.
- A screen view with scanpath, heatmap and AOIs, and a live topomap.
- The Dataset and Controls panels.

**EEG pipeline: preprocessing → epoching → analysis**, with up-to-date / out-of-date
tracking and background computation.
- **Preprocessing**:
  - automated peak-to-peak bad-channel detection;
  - filters (high-pass down to 0 Hz) and re-referencing;
  - ICA blink removal, scored against the eye tracker's blinks;
  - a component viewer;
  - an option to ignore the data before the first event.
- **Epoching**:
  - event groups with checklists and pandas-query filters;
  - epochs of any length, with a memory check;
  - peak-to-peak and flat rejection, blink dropping and an EEG-delay correction;
  - filters by subject, session, run and file;
  - a rejection report and an epoch timeline.
- **Analysis**:
  - ERP component presets (P1 … LPP) with window mean, peak amplitude and latency,
    and a Welch t-test, Mann-Whitney and Hedges' g between groups;
  - band power with a baseline after a baseline event, and an ERD/ERS time course;
  - cognitive indices: engagement, workload, θ/α, θ/β, frontal asymmetry, ERD/ERS and
    pupil dilation;
  - FDR-corrected comparisons and CSV/FIF export.

**Gaze tab**
- Oculomotor summary, histograms, main sequence, and AOI statistics with PyGaze.

**Montages**
- MNE montages and files.
- Channel layouts `gtec_64` and `gtec_unicorn`, plus your own layouts in
  `~/.brainstudio/montages/`.

## Notes

- The statistics treat epochs as observations, so they are within one recording. For
  group studies, export the per-epoch values.
- Full documentation: [README](https://github.com/itubrainlab/brainstudio#readme).
