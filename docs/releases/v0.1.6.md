An update to [brAInStudio 0.1.5](https://github.com/itubrainlab/brainstudio/releases/tag/v0.1.5).

## Fixes

- **Exported scripts, XDF marker streams with several columns** (start/stop, name,
  attributes): the script now reads them as the app does, pairing start and stop rows
  into one event with a duration. Groups of such events (e.g. `trials`) selected
  nothing in the script, which then failed with *max() iterable argument is empty*.
- **Exported scripts, drifting EEG clocks**: when the amplifier's rate drifts, the
  script now places the EEG samples at their true times as the app does. Before, its
  events could be off by up to the drift (90 ms on one recording). App and script give
  the same epochs on three XDF recordings.
- **Gaze sent as text** (e.g. Gazepoint streams with an empty USER field): fields that
  are not numbers are read as missing instead of stopping the load, in the app and in
  exported scripts.
- **Group ERP with three or more groups**: the repeated-measures ANOVA failed; it now
  runs.

## Changes

- **Restructured code** (model–view–controller). All analysis is plain functions in
  `brainstudio.core`, written like the exported scripts (MNE, MNE-BIDS, pyxdf,
  pymovements, AutoReject, scipy, pandas). The app's state is a Qt-free session
  (`brainstudio.session`); the windows only show it and pass actions to a controller.
  The modules `eeg`, `gaze`, `events`, `preprocessing`, `epoching`, `bandpower`, `stats`
  and `workflow` are gone: use `brainstudio.core` (see the README). Results are the same
  as 0.1.5, checked on synthetic data and on a 47-min, 64-channel XDF recording.

## Downloads

| System | File | Start |
|---|---|---|
| macOS (Apple Silicon) | `brAInStudio-0.1.6-macos-arm64.dmg` | open the DMG and drag brAInStudio to Applications; the first time, right-click → **Open** (the app is not notarized) |
| Windows (x86_64) | `brAInStudio-0.1.6-windows-x86_64.zip` | unzip and run `brAInStudio\brAInStudio.exe` (SmartScreen may ask you to confirm) |
| Linux (x86_64, glibc 2.35+) | `brAInStudio-0.1.6-linux-x86_64.tar.gz` | unpack and run `brAInStudio/brAInStudio` |
| Python | `brainstudio-0.1.6-py3-none-any.whl`, sdist | `pip install brainstudio-0.1.6-py3-none-any.whl` (Python ≥ 3.12) |

Each app was checked on its own system with `brAInStudio --self-test`. The self-test
loads a synthetic EEG and gaze dataset, then runs gaze event detection, preprocessing,
ICA with ICLabel, epoching with AutoReject, script export, ERP component statistics and
band power.

Full documentation: [README](https://github.com/itubrainlab/brainstudio#readme).
