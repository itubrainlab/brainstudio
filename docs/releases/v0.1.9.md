An update to [brAInStudio 0.1.8](https://github.com/itubrainlab/brainstudio/releases/tag/v0.1.8).

## New

- **Reference in preprocessing.** *Filtering & reference* in ① Preprocessing has a
  **Reference** choice again: as recorded (the default), the average, the mastoids
  (M1/M2, TP9/TP10, A1/A2 or P9/P10, the first pair present) or any EEG channel(s),
  e.g. `Cz` or `M1, M2`. It is applied to every subject after its bad channels are
  interpolated, over that subject's good EEG channels. Exported scripts apply the same
  reference with the same rule. The analyses can still re-reference on top: ERPs to
  the component's usual reference, band power to the average.

## Downloads

| System | File | Start |
|---|---|---|
| macOS (Apple Silicon) | `brAInStudio-0.1.9-macos-arm64.dmg` | open the DMG and drag brAInStudio to Applications; the first time, right-click → **Open** (the app is not notarized) |
| Windows (x86_64) | `brAInStudio-0.1.9-windows-x86_64.zip` | unzip and run `brAInStudio\brAInStudio.exe` (SmartScreen may ask you to confirm) |
| Linux (x86_64, glibc 2.35+) | `brAInStudio-0.1.9-linux-x86_64.tar.gz` | unpack and run `brAInStudio/brAInStudio` |
| Python | `brainstudio-0.1.9-py3-none-any.whl`, sdist | `pip install brainstudio-0.1.9-py3-none-any.whl` (Python ≥ 3.12) |

Each app was checked on its own system with `brAInStudio --self-test`. The self-test
loads a synthetic EEG and gaze dataset with stimuli, then runs gaze event detection,
stimulus video decoding, preprocessing, ICA with ICLabel, epoching with AutoReject,
script export, ERP component statistics and band power.

Full documentation: [README](https://github.com/itubrainlab/brainstudio#readme).
