An update to [brAInStudio 0.1.2](https://github.com/itubrainlab/brainstudio/releases/tag/v0.1.2)
that follows the ERP lessons of [neuraldatascience.io](https://neuraldatascience.io/eeg/erp-preprocessing/)
and exports every analysis as a script.

## New

- **Group ERPs per subject**:
  - each subject's epochs are averaged on their own (one Evoked per subject and
    group), then averaged with `mne.grand_average`, so every subject counts once;
  - 95 % confidence bands across subjects, a *Subjects* view, and difference waves per
    subject;
  - statistics across subjects: a paired t-test, Wilcoxon and Cohen's d_z, or a
    repeated-measures ANOVA and Friedman test for more groups;
  - per-subject tables, and each subject's own epoch-level test, FDR-corrected;
  - an optional spatio-temporal cluster / TFCE test of the subjects' difference waves.
- **ICLabel** ([MNE-ICALabel](https://mne.tools/mne-icalabel)) labels every ICA
  component (brain, eye blink, muscle, heart beat, line noise, channel noise, other)
  with its probability. Eye blink ≥ 70 % is suggested for removal.
- **Export script…** for ERP, band power and cognitive indices: a Python script in four
  cells (Loading, Preprocessing, Epoching, Analysis) that repeats the analysis with the
  settings the results on screen used. Standard steps are plain MNE, AutoReject and
  scipy code. The app runs the same functions, and a test checks that a script gives
  the app's data, epochs and tables exactly.
- **Subjects in the Data tab**: a labelled line where each subject's (and run's)
  recording starts, subjects shaded in the overview strip, and a Subject selector with
  ◀ ▶ to jump between them.

## Changes (following the ERP guide)

- **ICA** is fitted on a separate 1–30 Hz, average-referenced copy cut into 1 s
  segments. AutoReject leaves the bad segments out. Components explain 99 % of the
  variance, with `random_state=42` and every 3rd sample.
- **EOG stand-ins** without EOG channels are Fp1, Fp2, F7 and F8. The z threshold
  steps down from 3.5 until two components are found.
- **Epochs** default to −0.1…1.0 s with no fixed amplitude threshold. AutoReject
  interpolates bad channels per epoch and drops the epochs it cannot repair. The ERP
  baseline runs from the epoch start to 0 s.
- **Standard functions** replace own helpers: `mne.stats.f_mway_rm`,
  `scipy.stats.sem` and `Epochs.drop_bad`.
- The app is larger: it now includes MNE-ICALabel (ONNX Runtime) and AutoReject.

## Downloads

| System | File | Start |
|---|---|---|
| macOS (Apple Silicon) | `brAInStudio-0.1.3-macos-arm64.dmg` | open the DMG and drag brAInStudio to Applications; the first time, right-click → **Open** (the app is not notarized) |
| Windows (x86_64) | `brAInStudio-0.1.3-windows-x86_64.zip` | unzip and run `brAInStudio\brAInStudio.exe` (SmartScreen may ask you to confirm) |
| Linux (x86_64, glibc 2.35+) | `brAInStudio-0.1.3-linux-x86_64.tar.gz` | unpack and run `brAInStudio/brAInStudio` |
| Python | `brainstudio-0.1.3-py3-none-any.whl`, sdist | `pip install brainstudio-0.1.3-py3-none-any.whl` (Python ≥ 3.12) |

Each app was checked on its own system with `brAInStudio --self-test`. The self-test
loads a synthetic EEG and gaze dataset, then runs preprocessing, ICA with ICLabel,
epoching with AutoReject, ERP component statistics and band power.

Full documentation: [README](https://github.com/itubrainlab/brainstudio#readme).
